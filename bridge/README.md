ZKTeco Bridge for GymFlow

This project runs on a Windows machine in a gym and connects a local ZKTeco device to the GymFlow cloud.

Quick start

1. Copy `config.json.example` to `config.json` and edit values.
2. Install Python 3.11 and create a venv, then:

```bash
pip install -r requirements.txt
python main.py
```

When packaged with PyInstaller, run the generated .exe and allow it to auto-start.
